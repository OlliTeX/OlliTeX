## Finding (autonomous audit, 2026-10-11 — spun off from TODO-70eaabb0, audit verdict there)
The federation export handler advertises a public clone URL the host does not serve:

- `go/services/web/features/federation/s2s_actions.go:429-435` — `exportGitURL(projectId) = https://<B-host>/git/<projectId>`;
- `s2s_actions.go:527` — included in the export response payload as `git_url`;
- but on both known host shapes **nothing serves /git/**: `toolkit/web/haproxy.cfg` has zero git lines; `images/main-amd64/nginx/nginx.conf.template` has no `/git/` location; git-bridge containers publish no host ports (`ol-e2e-git-bridge-1` 8000/tcp→null; prod `git-bridge` Exited with empty Ports).

→ A peer that follows the advertised `git_url` gets a 404/421 from the web edge, not a git repo. Federation is currently NOT a live feature on this host (no peer connected per earlier waves), so the impact is latent — but it is a broken contract in the exchange payload.

## Owner decision (either/or)
1. **Serve it properly** (recommended if federation is a product goal): add an edge route in the haproxy equivalent of the upstream allowlist shape (upstream git source: `origin <https://github.com/saveli/overleaf-cep.git>`, branch `fix/git-bridge-nginx-allowlist`, commit `44a44547eb230b8078e2f876236debcd849dd376` — 404 everything under /git/ except `^/git/[0-9a-f]{24}(\.git)?(/|$)`), pointing at the git-bridge service; the git servlet endpoints are already Oauth2Filter-protected (PAT of a federation minted user); the unauthenticated DELETE / internals stay 404. CREDITS entry required (git-source citation, same commit).
2. **Stop advertising it** until we have a serving path: drop `git_url` from the export payload (or mark it unreachable) so a peer doesn't get a promise the host can't keep.

## Constraints
- Option 1 opens a public port: the unauthenticated `DELETE /api/projects/<id>` (gitbridge `server/delete.go:33`, dormant — no in-tree caller) MUST stay outside the allowlist (it is, in the upstream shape) — pin this in the e2e `git-bridge-edge-probe` spec (test-wave TODO-682370f6 #8).
- Option 2 is a one-liner in `exportProject` + response-shape test if one exists (`zz_live_fedb_test.go` / `rp_test.go` cover federation routes — check whether git_url is asserted anywhere).
- Either way: live probe evidence read-only (GETs only; no destructive DELETEs at the edge).
