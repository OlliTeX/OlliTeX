## Audit 011 — "Show version history" says "something went wrong" — DONE (live E2E verified 2026-10-01)
Commit d7f2c1e3a9 (daba4b65d7).

### Root cause (two layers)
1. **Route:** `GET /project/:id/diff?from&to[&pathname]` was wired to the raw V2 proxy. In this stack the version store of record is the Yjs plane (collab rooms in mongo `ydoc`), so V2 404'd every Yjs project → Node-parity 500 HTML page → the panel's react-error-boundary fired → "Sorry, something went wrong."
2. **Data:** history-v1 (V1, :3100) had never seeded its S3 `chunks` bucket (SeaweedFS 403 at creation time 09-30) → `changes` 500 "no chunks for project" for all 185 projects.

### Fix
- `go/services/web/features/history/handlers.go`: new `h.projectDiff` — Yjs-first (same `{diff:[u|i|d,meta?]}` wire as the doc diff; room root doc is the rendered content on the single-doc plane), legacy V2 passthrough fallback for uncovered ranges (byte-pinned Node behavior). Malformed range → legacy path unchanged.
- `history.go`: `diffPat` → `h.projectDiff`; doc comment updated.
- **Data repair (live):** V1 `POST /api/projects` initialize for all 185 projects → 183 initialized + 2 already + 0 failed (SeaweedFS now 200 on writes; the 09-30 403 was transient).
